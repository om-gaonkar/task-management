# Daymark client

React, Vite, TypeScript, React Router, TanStack Query, and custom CSS/UI primitives (no shadcn/ui).

## Setup

1. Copy `.env.example` to `.env` and set `VITE_API_URL`.
2. Run `npm install`.
3. Run `npm run dev`.

## Status

The responsive shell, theme control, shared query client, fetch wrapper, and initial dashboard/task/project/diary screens are present. The content on those screens is preview/local-only data. Authentication screens and server-backed feature integrations are not complete. Do not use the local diary draft for private content.
