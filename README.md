# Personal Productivity Workspace

A full-stack personal workspace built with React, Vite, TypeScript, Tailwind CSS, Express, MongoDB, and Mongoose.

## Project layout

- `client/` — React + Vite frontend
- `server/` — Express API and modular domain services

## Development

See `docs/architecture.md` and the individual `client/README.md` and `server/README.md` files.

This repository is initialized incrementally. External integrations (Google OAuth and Cloudinary) are optional and must be configured explicitly. No secrets belong in source control.
